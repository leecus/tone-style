# Tone — 组件库与设计规范

Tone 是一套面向后台管理界面的轻量级组件库与设计规范。聚焦于极简美学与实用性，提供从设计 Token 到完整页面的系统化参考。

## 快速预览

👉 [tone-style.vercel.app](https://leecus.github.io/tone-style/)（GitHub Pages）

## 内容

- **Design Tokens** — 色彩、字体、间距等设计原子
- **Layout** — 侧边栏 / 顶部导航两套布局系统
- **Components** — 品牌、导航、按钮、表单、表格、标签、弹窗、提示、下拉菜单等 18 个组件板块
- **Mobile Web** — 移动端适配组件（底部标签栏、抽屉菜单、触控表单等）
- **Responsive** — 响应式断点适配桌面和平板/手机

## 使用方式

直接打开 `index.html` 即可浏览全部组件规范。所有样式内联在 HTML 中，无需构建工具。

## 技术栈

- 原生 HTML / CSS
- Google Fonts（Instrument Serif + Outfit + JetBrains Mono）
- 纯 CSS 组件（无 JavaScript 依赖）
